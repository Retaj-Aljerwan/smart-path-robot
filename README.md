## 🎯 Project Overview

Smart Path is an autonomous robotic system developed as a course project for RME301.  
The project applies concepts of robotics, sensors, control logic, and Python programming  
using the Codey Rocky robot and mBlock.

The robot combines three main functionalities:

- 🎨 Color Detection
- 🚧 Obstacle Avoidance
- 🛣️ Line Following

## ⚙️ Technologies

- Python
- mBlock 5
- Codey Rocky
- Color Sensor
- Infrared Sensors
- Distance Sensor

## 🧠 How It Works

The robot uses button-based modes to switch between its main functions:

**Button A — Color Detection**  
Detects different colors and displays the identified color.

**Button B — Obstacle Avoidance**  
Uses distance sensing to detect obstacles and adjust the robot's movement.

**Button C — Line Following**  
Uses sensor readings to follow a black line on a white surface.

## 📊 Results

The three functionalities were developed and tested individually and then integrated  
into a single control program. The system successfully performed color detection,  
line tracking, and obstacle avoidance under controlled conditions.

## 🛠️ Challenges

During the project, we faced challenges with:

- Integrating multiple functions into one control program
- Limited processing speed when combining functions
- Conflicts between obstacle avoidance and line following
- Sensor calibration and environmental lighting

These challenges helped us improve our problem-solving, debugging, and system integration skills.
